## Project Description
This project is a fully responsive portfolio website built with HTML and CSS. The goal was to practice CSS fundamentals, the box model, typography, color systems, Flexbox, Grid, and mobile-first responsive design to create a professional, visually appealing site.

## Technologies Used
- HTML5  
- CSS3  
- Google Fonts (Montserat, Open Sans)  
- CSS Custom Properties (Variables)  
- Flexbox  
- CSS Grid  

---

## Features
- Fully responsive layout for mobile, tablet, and desktop  
- Custom typography system with clear hierarchy  
- Color system using CSS variables  
- Card components with image, title, description, and button  
- Responsive navigation bar and footer  
- Interactive hover and focus states for buttons and links  

---

## How to Run
1. Clone this repository  
2. Open `index.html` in your browser  

---

## Lessons Learned
- Deepened understanding of the CSS box model and spacing  
- Practiced creating responsive layouts using Flexbox and Grid  
- Learned to implement a consistent typography and color system  
- Improved mobile-first design skills  

---

## Challenges Faced
- Adjusting card images to fit correctly without breaking layout  
- Making the footer stick correctly while keeping responsive spacing  
- Solving layout issues caused by default margins and padding
